## Differences from the mock-up we keep on purpose

- The mock-up's numbers are from before the plan change of 2026-11-18. The app shows today's plan: abs 17 (not 27) and
  calves 9 (not 3) in weeks 2 to 5, so fewer things "stand out". The rule is the mock-up's; the numbers are live.
- The muscle check counts the days **as Rosario will train them** (saved edits included), so an Add for a "low" muscle
  shows up there at once. "This screen only shows numbers. It never changes the plan." stays.
- The bars use CSSOM widths set from code (no `style` attribute in the markup), as the body maps do.
- Abs place choice of builder B (t-add second card, `v72b`) is the answer-72-b version and is not built (answer 72 a).
