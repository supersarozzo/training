## What was built
- `autosync.js`: a full sync about 10 s after the last save of synced data; at once on going to the background
  (hidden, pagehide) and on open or front when something is not sent (5-minute limit only for news); on signal back;
  never during a workout (Finish sends it). Loop guard: the screens save through `withSaveSignal` stores, the syncers
  through the plain ones.
- Back-off (Training Agent): `sync.js syncProblem` reads the saved `last_sync_result`. With a problem the quiet time
  and the way out send nothing; "retry" problems try again on open, front, signal back or "Sync now"; a wrong key, no
  access or a damaged GitHub file waits for "Sync now" or a new key. Only the workout result counts.
- Settings: one status line ("Synced 12:25." / "Not sent yet, will send automatically." / the problem in words), "Sync
  now", Get and Send under "More". Today and the food line use the same words.
- Version 0.7.2 in version.js and the sw.js cache name; no new app files.
